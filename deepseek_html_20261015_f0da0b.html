Установка за 5 шагов

Вся установка — одна команда. Она скачает Python, venv, зависимости, Ollama, модели и запустит приложение.

Открой PowerShell от администратора

Нажми Win + X → выбери Windows PowerShell (администратор) или Терминал (администратор).

Скопируй команду

Вернись наверх и нажми кнопку «СКАЧАТЬ — 1 КОМАНДА». Команда попадёт в буфер обмена.

Вставь и запусти

В PowerShell нажми Ctrl + V (или правой кнопкой мыши) и жми Enter. Установка начнётся автоматически.

Дождись мигающих глаз 0_0 -_-

Скрипт скачает базовые пакеты, потом покажет анимацию и будет ждать. Нажми Enter — установка продолжится (torch, diffusers, Ollama, модели).

Приложение запустится само

Через 5–15 минут (в зависимости от интернета и наличия NVIDIA) откроется окно АНТИ КЛАУД 4. Пиши свой первый запрос!

💡 Совет: как запустить потом

После установки приложение лежит в %USERPROFILE%\AntiCloud\app.py. Чтобы запустить снова, открой PowerShell и введи:

cd $HOME; .\AntiCloud\venv\Scripts\Activate.ps1; python .\AntiCloud\app.py

Частые вопросы

Если что-то не работает — сначала посмотри здесь.

PowerShell выдаёт ошибку «выполнение сценариев отключено»
Открой PowerShell от админа и выполни: Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned.
Подтверди буквой Y и попробуй снова.
winget не найден
Обнови Windows до последней версии или поставь App Installer из Microsoft Store. Если не помогает — Python и Ollama придётся поставить вручную с официальных сайтов.
Установка зависла на «torch»
Это нормально — torch весит 2–3 ГБ. Если стоит NVIDIA CUDA-версия, может занять 10–15 минут. Не закрывай окно. Если совсем долго — проверь интернет.
Картинки генерируются очень долго
Скорее всего, у тебя нет NVIDIA GPU (или CUDA не установлена), и Z-Image работает на CPU. Это нормально — 3–5 минут на картинку. Хочешь быстрее — нужна видеокарта NVIDIA с 6+ ГБ VRAM.
Ошибка «ZImagePipeline not found»
Z-Image Turbo — экспериментальная модель в diffusers. Иногда её пайплайн называется иначе. Проверь: pip install git+https://github.com/huggingface/diffusers.git. Если не помогает — напиши разработчику.
Ollama не запускается / модели не качаются
Проверь, что служба Ollama запущена: ollama serve. Если порт 11434 занят — закрой другие ИИ-приложения. Модели качаются с ollama.com — если у тебя блокировка, используй VPN.
Водяной знак можно отключить?
Да, но приложение обидится покажет диалог с вопросом. Водяной знак — единственная «реклама» проекта, поэтому мы просим его оставить. Но кнопка «Всё равно отключить» есть.
Как удалить АНТИ КЛАУД 4?
Удали папку %USERPROFILE%\AntiCloud. Модели Ollama лежат в %USERPROFILE%\.ollama — удали вручную, если не нужны. Больше ничего не остаётся.
